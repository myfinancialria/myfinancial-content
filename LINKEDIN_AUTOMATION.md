# LinkedIn share automation

Turns each day's published articles into ready-to-post LinkedIn assets:

1. **Heading + TL;DR** — pulled straight from the article markdown
   (`# H1` and the `**TL;DR**` bullet block).
2. **9:16 poster** (`poster.jpg`, 1080×1920) — an AI-generated background
   (Pollinations FLUX, the same free engine as `generate_image.py`) with the
   heading and TL;DR overlaid as crisp text + `myfinancial.in` branding.
   We overlay the text ourselves because text-to-image models can't render
   text reliably.
3. **Simple caption** (`caption.txt`) — one short, plain-English paragraph
   (written by the LLM in `llm.py`) to paste when sharing/reposting on
   LinkedIn, followed by the article link and hashtags.

Everything lands under [`output/linkedin/`](output/linkedin/), and an
[`output/linkedin/index.html`](output/linkedin/index.html) gallery lets you
download each poster and copy its caption in one click.

> Posting itself stays manual by design — no LinkedIn API app / OAuth tokens
> needed. Open the gallery, download the poster, copy the caption, post.

## Daily run

A step in [`.github/workflows/generate.yml`](.github/workflows/generate.yml)
(**Generate LinkedIn share posters + captions**) runs right after hero-image
generation, so today's posters are committed alongside the articles in the
same `output/` commit and published to the site.

It processes **today's (UTC)** articles by default. To also cover the
explainer / pre-market / post-market pieces (generated by their own
workflows), add the identical step to `explainer.yml`,
`generate_premarket.yml`, and `generate_postmarket.yml`.

## Run it yourself

```bash
pip install -r requirements.txt

python linkedin_poster.py                      # today's (UTC) articles
python linkedin_poster.py --date 2026-06-27    # a specific day
python linkedin_poster.py --slug 2026-06-27-macro-...-guide
python linkedin_poster.py --category macro     # one category
python linkedin_poster.py --force              # rebuild existing posters
```

It is **idempotent**: an existing `poster.jpg` is skipped unless `--force`
is set, so it's safe to invoke from several workflows on the same day.

## How it degrades

- **No LLM key / LLM down** → a templated caption (from the heading + TL;DR)
  and a templated background prompt are used. Posters still generate.
- **Pollinations down** → falls back to a clean navy gradient background.
  Text overlay is unaffected, so the poster is still usable.

## Knobs

- Fonts: bundled Poppins in [`assets/fonts/`](assets/fonts/) (SIL OFL).
- Palette / dimensions / layout: constants at the top of
  [`linkedin_poster.py`](linkedin_poster.py) (`W`, `H`, `NAVY`, `AMBER`, …).
- Hashtags: `HASHTAGS` in `linkedin_poster.py`.
